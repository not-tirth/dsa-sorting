
# DSA Practice - Arrays and Sorting

## Project Overview
This project contains 5 basic DSA programs written in C++.
These programs help beginners understand arrays, loops, conditions, and sorting.



### 1. Remove Duplicate Elements
- Takes array elements from the user.
- Removes repeated elements.
- Displays unique elements.

### 2. Find Largest and Second Largest
- Finds the largest number in an array.
- Finds the second largest different number.
- Handles duplicate elements.

### 3. Sort Array in Ascending and Descending Order
- Takes array elements from the user.
- Sorts numbers in ascending order.
- Sorts numbers in descending order.
- Uses Bubble Sort.

### 4. Count Positive and Negative Numbers
- Counts positive numbers.
- Counts negative numbers.
- Ignores zero.

### 5. Sort Even and Odd Numbers Separately
- Separates even and odd numbers.
- Sorts even numbers in ascending order.
- Sorts odd numbers in descending order.
- Displays even and odd numbers separately.

## Concepts Used
- Arrays
- For Loops
- If-Else Conditions
- Bubble Sort
- Swapping Elements
- Array Traversal

## Technologies Used
- Language: C++
- Compiler: GCC / MinGW
- Editor: Visual Studio Code
